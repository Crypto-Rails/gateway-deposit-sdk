deposit-watch — demo

Serve the project root (npx serve .) and open this at /examples/demo.html after npm run build.

Function 1 — watchDeposits()

QR modal + polling. Address is checksum-validated on open. Detection defaults to positive (any balance = deposit); onDeposit fires an (awaited) API call the instant funds land. Set a min deposit to require a minimum amount — the modal keeps polling (showing partial progress) until the running total is enough, so a payment can arrive in installments.

Shown as the header. The small line beneath it is the localized “Fund your account” for the chosen language.

Each row is one receiving target (address · token · chain). Add several to watch multiple addresses / chains at once — the modal shows a tab per target. Whether it resolves on the first funded target or waits for all of them is the Resolve on control below.

Appearance & language — the modal is fully localizable and restyleable.

Function 2 — getBalances()

Pass any mix of addresses, tokens, and native coins — even across chains — as one target list. EVM targets on the same chain share a single Multicall3 call, and results come back in the same order. Each row below is one independent target (blank token = the chain's native coin). Try Ethereum with 0x55FE002aefF02F77364de339a1292923A15844B8 (Circle).
